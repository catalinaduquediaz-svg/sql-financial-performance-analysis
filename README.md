# 📊 Financial Performance Analysis with SQL

## 📌 Descripción

Proyecto desarrollado durante el Bootcamp de Análisis de Datos de TripleTen para evaluar el desempeño financiero de diferentes mercados mediante consultas SQL y el análisis de indicadores de rentabilidad.

---

## 🎯 Objetivo

Analizar el desempeño financiero por país para responder dos preguntas clave del negocio:

- ¿Cuánto estamos ganando por país?
- ¿Qué tan rentable es cada mercado considerando los gastos de marketing?

---

## 🛠️ Herramientas utilizadas

- SQL
- Microsoft Excel

---

## 📈 Indicadores analizados

- Ingresos
- Costos
- Beneficio bruto
- Margen
- ROI (Retorno sobre la inversión)

---

## 📊 Proceso realizado

- Consulta y análisis de datos mediante SQL.
- Cálculo de indicadores financieros.
- Comparación de resultados por país.
- Elaboración de un resumen ejecutivo con hallazgos y recomendaciones.

---

## 💡 Principales hallazgos

- Se comparó la rentabilidad entre distintos mercados.
- Se identificaron diferencias en el margen y el ROI por país.
- El análisis permitió evaluar la eficiencia de la inversión en marketing y detectar oportunidades de mejora.
