# 📊 Análisis del Desempeño Financiero con SQL

Proyecto de **Data Analytics** desarrollado con **SQL** para analizar el desempeño financiero de diferentes mercados mediante indicadores de ingresos, costos, rentabilidad y retorno sobre la inversión (ROI).

---

## 📌 Resumen ejecutivo

Este proyecto utiliza consultas SQL para transformar datos financieros en información estratégica, permitiendo comparar el desempeño económico entre distintos países y evaluar oportunidades de mejora en la rentabilidad.

El análisis se centra en la construcción de consultas, agregaciones y métricas financieras para apoyar la toma de decisiones basada en datos.

## 🎯 Problema de negocio

Una empresa con operaciones en múltiples mercados necesitaba identificar qué países presentaban un mejor desempeño financiero y cuáles requerían estrategias de optimización.

Las principales preguntas fueron:

* ¿Qué países generan mayores ingresos?
* ¿Cómo varían los costos entre mercados?
* ¿Qué países presentan mejor margen de utilidad?
* ¿Dónde se obtiene un mayor retorno sobre la inversión (ROI)?

## ✅ Objetivos del proyecto

* Analizar indicadores financieros mediante SQL.
* Comparar el desempeño económico entre países.
* Calcular métricas de rentabilidad y retorno.
* Comunicar hallazgos mediante un resumen ejecutivo.

## 💡 Principales hallazgos

* Se identificaron diferencias significativas de rentabilidad entre mercados.
* El análisis permitió comparar ingresos y costos mediante consultas SQL agregadas.
* El cálculo del margen y del ROI facilitó evaluar el desempeño financiero por país.
* Los resultados sirven como apoyo para priorizar estrategias comerciales e inversiones.
